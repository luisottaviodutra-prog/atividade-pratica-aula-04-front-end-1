# Respostas das atividades

## Atividade 1
**Resposta:** 
O arquivo `index.html` é responsável pela estrutura e pelo conteúdo da página web. O arquivo `style.css` é responsável pela aparência, estilo e layout da página.

## Atividade 2
**Resposta:** 
A declaração `<!DOCTYPE html>` deve aparecer no início do documento para indicar que ele utiliza o padrão HTML5.

## Atividade 3
**Resposta:** 
A tag `<title>` deve ser utilizada dentro da seção `<head>` para definir o título que aparece na aba do navegador.

## Atividade 4
**Resposta:** 
A tag `<h1>` representa o título principal da página e a tag `<p>` representa um parágrafo de texto.

## Atividade 5
**Resposta:** 
O elemento HTML5 `<section>` deve ser utilizado para representar uma seção temática de conteúdo.

## Atividade 6
**Resposta:** 
O elemento `<nav>` agrupa links de navegação. O atributo `href` da tag `<a>` define o destino do link.

## Atividade 7
**Resposta:** 
O atributo `id` deve ser utilizado para identificar unicamente uma seção. Para apontar para uma seção chamada `sobre`, o valor do atributo `href` deve ser escrito como `#sobre`.

## Atividade 8
**Resposta:** 
A tag `<img>` deve ser utilizada para inserir uma imagem. O atributo `src` define o caminho do arquivo da imagem.

## Atividade 9
**Resposta:** 
Os elementos HTML5 `<figure>` e `<figcaption>` devem ser utilizados para agrupar a imagem e sua respectiva legenda, respectivamente.

## Atividade 10
**Resposta:** 
O atributo `href` deve ser utilizado para definir o endereço de destino de um link externo ou interno.

## Atividade 11
**Resposta:** 
Um link interno direciona para outro arquivo ou recurso localizado dentro do próprio projeto ou para uma âncora na mesma página, enquanto um link externo direciona para um endereço da web fora do projeto.

## Atividade 12
**Resposta:** 
A tag `<table>` representa a tabela, `<tr>` representa uma linha, `<th>` representa uma célula de cabeçalho e `<td>` representa uma célula comum de dados.

## Atividade 13
**Resposta:** 
O valor `mailto:` deve ser utilizado no atributo `href` (ex: `href="mailto:contato@exemplo.com"`) para criar um link que abre o aplicativo de e-mail padrão.

## Atividade 14
**Resposta:** 
O elemento HTML5 `<footer>` deve ser utilizado para representar o rodapé de um documento ou seção.

## Atividade 15
**Resposta:** 
A tag `<link>` deve ser utilizada para relacionar o documento a uma folha de estilos externa. O atributo `rel="stylesheet"` informa que o arquivo relacionado é uma folha de estilos.

## Atividade 16
**Resposta:** 
A propriedade CSS `font-family` define a família da fonte de um elemento.

## Atividade 17
**Resposta:** 
A propriedade CSS `color` define a cor do texto e a propriedade `text-align` define o alinhamento horizontal do texto.

## Atividade 18
**Resposta:** 
Podemos selecionar dois ou mais elementos diferentes em uma mesma regra CSS agrupando-os separados por vírgula (ex: `h2, h3`).

## Atividade 19
**Resposta:** 
O símbolo de ponto (`.`) deve ser utilizado no CSS para selecionar uma classe. O atributo HTML `class` deve ser utilizado para associar um elemento a essa classe.

## Atividade 20
**Resposta:** 
O símbolo de cerquilha ou jogo da velha (`#`) deve ser utilizado no CSS para selecionar um elemento pelo seu ID.

## Atividade 21
**Resposta:** 
A propriedade CSS `width` define a largura de um elemento. O valor `auto` pode ser utilizado para ajustar automaticamente a altura proporcionalmente.

## Atividade 22
**Resposta:** 
A propriedade CSS `padding` define o espaçamento interno de um elemento.

## Atividade 23
**Resposta:** 
A propriedade CSS `margin` define o espaçamento externo de um elemento. A expressão `margin: 0 auto` tem a função de centralizar um elemento de bloco horizontalmente na tela.

## Atividade 24
**Resposta:** 
A propriedade CSS `float` permite que um elemento flutue para um dos lados. O valor `left` deve ser utilizado para posicionar a imagem à esquerda.

## Atividade 25
**Resposta:** 
A propriedade `width` define a largura da tabela, `border-collapse` permite unificar as bordas das células, e a propriedade `border` define a espessura, estilo e cor da borda de um elemento.

## Atividade 26
**Resposta:** 
A propriedade CSS `text-decoration` controla a decoração do texto. O valor `none` remove o sublinhado padrão dos links.

## Atividade 27
**Resposta:** 
Para estilizar o rodapé conforme solicitado, utilizamos as propriedades `background-color: lightgray;`, `padding: 15px;` e `text-align: center;`.
